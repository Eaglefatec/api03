# US-03 | Prioridade: Alta | Sprint: 1

## 1. Estrutura Padrão

Como EG
Eu quero consultar as Pré-guias
Para auxiliar o preenchimento da GUIA no sistema da Fusex. 

## 2. Contexto & Descrição Detalhada

**Justificativa:**

Assim como a Emissão da Pré-Guia pelo Beneficiário, é necessário também que o próprio Emissor da Guia possa não só “consultar as pré-guias” como também “criar uma pré-guia”.
Essa Pré-guia ajudará o EG (Emissor de Guia) a buscar as informações necessárias.

## 3. Critérios de Aceite

**Regras de Negócio e Funcionais:**

* EG deve conseguir consultar as pré-guias aguardando emissão;
* EG deve confirmar que a Guia relacionada àquela pré-guia já foi emitida;
* Cada encaminhamento-médico só pode ter uma guia relacionada;
* EG deve ser capaz de “cadastrar uma pré-guia” no sistema, caso o beneficiário não tenha conhecimento tecnológico para isso;
* Sistema não deve permitir que o beneficiário solicite um exame ou procedimento que não existe na OCS;
* Ao selecionar exame + OCS, o sistema deve já vincular o “preço” do exame/procedimento.

**Cenários BDD:**

**Cenário 1:** O EG escolhe uma pré-guia e emite a Guia
* Dado que a pré-guia está com status “Pendente”
* Quando o EG seleciona, confirma e emite
* Então a guia recebe status de “Emitida” e mostra a data de emissão atual.

**Cenário 2:** Emissão duplicada
* Dado que já existe uma guia emitida para esse Beneficiário/exame
* Quando o EG tenta emitir novamente
* Então aparece a mensagem de erro: “Já existe uma guia emitida”.

**Cenário 3:** Falta de arquivo de Encaminhamento
* Dado que não há arquivo de Encaminhamento anexado
* Quando o EG tenta emitir a Guia sem o Encaminhamento
* Então aparece a mensagem: “Encaminhamento não encontrado”.
