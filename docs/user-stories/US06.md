# US-06 | Prioridade: Baixa | Sprint: 3

## 1. Estrutura Padrão

Como Chefe / Médico
Eu quero assinar as guias digitalmente
Para tornar esse processo mais rápido e eficiente

## 2. Contexto & Descrição Detalhada

**Justificativa:**

Ficar assinando em punho e validar dados em documentos físicos é bastante trabalhoso. Bem como a logística do documento que é transportado fisicamente entre os setores da FUSEX.
Um documento digital não está suscetível a perdas.

## 3. Critérios de Aceite

**Regras de Negócio e Funcionais:**

* O chefe da FUSEX / Médico deve ser capaz de consultar de forma centralizada as guias que estão aguardando autorização;
* O chefe deve ser capaz de assinar essa guia digitalmente (marcando um checkbox de validação/assinatura com credenciais seguras);
* O chefe deve ser capaz de reprovar uma GUIA com justificativa;
O EG deve ser capaz de consultar as "guias já assinadas" pelos chefes da FUSEX.

**Cenários BDD:**

**Cenário 1:** Consulta à fila de guias pendentes de assinatura
* Dado que o Chefe da FUSEX / Médico está autenticado no painel de aprovações
* Quando acessa a seção de guias aguardando autorização
* Então o sistema exibe a lista com todas as guias pendentes ordenadas por data de submissão.

**Cenário 2:** Assinatura digital via marcação de checkbox e validação
* Dado que o Chefe / Médico seleciona uma guia específica para análise
* Quando ele revisa o documento e marca o checkbox de assinatura digital confirmando a autorização
* Então o sistema aplica o carimbo digital, altera o status para "Assinada/Aprovada" e registra o ID do usuário responsável.

**Cenário 3:** Consulta do EG às guias já assinadas
* Dado que o EG precisa acompanhar o andamento dos documentos
* Quando ele acessa o módulo de rastreio e filtra pelas "guias já assinadas"
* Então o sistema exibe a listagem completa das guias que passaram pela aprovação dos chefes/médicos e estão prontas para as etapas seguintes.
