# US-07 | Prioridade: Média | Sprint: 2

## 1. Estrutura Padrão

Como OCS
Eu quero receber a Guia e checar a validade dela
Para não correr o risco de glosa por perda de validade.

## 2. Contexto & Descrição Detalhada

**Justificativa:**

Hoje, um beneficiário chega na OCS com um papel, e pede para fazer o exame.
Nem sempre o atendente da OCS consegue validar tudo o que precisa para o exame. Às vezes, eles fazem um procedimento após o prazo de validade da guia.

## 3. Critérios de Aceite

**Regras de Negócio e Funcionais:**

* O atendente da OCS deve ser capaz de, com a guia em mãos, identificar de forma visual e evidente se uma GUIA já passou do prazo de validade
* O sistema deve possibilitar a leitura das informações da GUIA ou código identificador pela OCS;
* O sistema deve bloquear ou emitir alerta impeditivo caso a OCS tente registrar/validar uma guia vencida;
* O status de validade (VÁLIDA / VENCIDA) deve ser atualizado em tempo real com base na data do atendimento.

**Cenários BDD:**

**Cenário 1:** Consulta de Guia dentro do prazo de validade (Validação com Sucesso)
* Dado que o atendente da OCS está autenticada no sistema e o beneficiário apresenta a Guia
* Quando o atendente digita o código da Guia que está dentro do prazo de validade
* Então o sistema exibe os dados da Guia com indicador visual destacado na cor verde "GUIA VÁLIDA" e permite prosseguir com o atendimento.

**Cenário 2:** Consulta de Guia com prazo expirado
* Dado que o atendente da OCS está na tela de validação <br>
* Quando o atendente digita o código de uma Guia cuja data limite já expirou <br>
* Então o sistema exibe em destaque vermelho o alerta "GUIA VENCIDA - FORA DA VALIDADE" e impede o registro do procedimento para a Guia.

**Cenário 3:** Leitura de Guia inexistente ou inválida
* Dado que o atendente tenta validar uma Guia
* Quando insere um código ou lê um inválido/não reconhecido
* Então o sistema exibe a mensagem de erro: "Guia não encontrada no sistema. Verifique o código informado."
