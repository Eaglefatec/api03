# US-09 | Prioridade: Média | Sprint: 2

## 1. Estrutura Padrão

Como ACM
Eu quero digitalizar o cruzamento dos dados recebidos da OCS com as condições contratadas
Para ter um relatório de divergências automatizado.

## 2. Contexto & Descrição Detalhada

**Justificativa:**

Hoje os documentos são recebidos de forma heterogênea. Alguns por planilhas, outros por arquivos impressos.
Isso dificulta as análises, gerando grande esforço cognitivo.
Um cruzamento de dados vai poupar grande esforço cognitivo em ficar caçando divergências de valores a olho nu.

## 3. Critérios de Aceite

**Regras de Negócio e Funcionais:**

* Receber os dados de ESPELHO, GUIAS-ASSINADAS e FATURAS de uma OCS relacionados a um determinado mês;
* Validar e comparar automaticamente as mudanças/inconsistências entre "Espelho", "Guias" e a tabela de "Preços por serviço x OCS" contratada;
* Gerar um Relatório Automatizado de Divergências apontando diferenças de preços, itens não previstos ou inconsistências de valores;
* O sistema deve permitir a geração de uma glosa (parcial ou total) para uma GUIA e enviá-la diretamente para a OCS.

**Cenários BDD:**

**Cenário 1:** Cruzamento sem divergências encontradas <br>
* Dado que o ACM seleciona o lote mensal de uma OCS contendo Espelho, Fatura e Guias
* Quando executa a rotina de "Cruzamento de Dados" com a tabela contratada
* Então o sistema valida todas as informações e apresenta o relatório com o status "Sem divergências encontradas".

**Cenário 2:** Identificação automática de divergência de preço cobrado vs. contrato <br>
* Dado que a OCS cobrou um valor de serviço superior ao valor acordado na tabela de Preços x OCS
* Quando o processamento de cruzamento é concluído
* Então o sistema destaca a linha do serviço no Relatório de Divergências exibindo o valor cobrado vs. o valor contratado.

**Cenário 3:** Geração e envio de Glosa para a OCS <br>
* Dado que o ACM identificou uma divergência no relatório gerado
* Quando o ACM seleciona a Guia divergente, informa o motivo da rejeição e clica em "Gerar Glosa"
* Então o sistema registra a glosa para aquela Guia, atualiza o valor faturável e envia a notificação de glosa para a OCS.
